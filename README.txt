IDRIS SUPERMARKET PRO — نسخه آغازین قابل اجرا

اجرا:
1) فایل ZIP را Extract کنید.
2) در کمپیوتر فایل index.html را با Chrome یا Edge باز کنید.
3) برای نصب موبایل، تمام فایل‌ها را روی GitHub Pages یا هاست HTTPS آپلود کنید؛ لینک را در Safari/Chrome باز کنید و Add to Home Screen را انتخاب کنید.
4) اولین بار که سیستم باز شود، کود مدیر ۴ تا ۱۲ رقمی را خودتان تعیین کنید.

امکانات موجود:
- داشبورد، ثبت/ویرایش/حذف اجناس
- واحدهای دانه، کیلو، گرام، بوجی، کارتن، بسته و لیتر
- بارکد دستی، پشتیبانی اسکن دوربین در مرورگرهای دارای BarcodeDetector و اسکنر USB
- سبد خرید، فروش، محاسبه باقی‌پول و چاپ رسید
- واحدهای پولی متعدد با نرخ تبدیل دستی
- موجودی گدام و هشدار کمبود
- ثبت مصارف
- گزارش CSV
- پشتیبان‌گیری و بازیابی JSON
- تغییر کود مدیر و درخواست امکانات جدید

محدودیت مهم:
این نسخه داده‌ها را در حافظه همان مرورگر/دستگاه نگهداری می‌کند. آنلاین/آفلاین بودن صفحه به معنی همگام‌سازی بین دستگاه‌ها نیست. همگام‌سازی امن موبایل و کمپیوتر به سرور و پایگاه داده ابری نیاز دارد و هنوز در این نسخه فعال نشده است. کود مدیر قفل محلی ساده است و سامانه امنیتی چندکاربره سرورمحور نیست. پیش از استفاده تجارتی، آن را آزمایش و مرتب نسخه پشتیبان تهیه کنید.
